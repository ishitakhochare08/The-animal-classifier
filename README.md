🦁 Animal Classifier

A simple, interactive console-based Python application that classifies different animals into their respective biological categories (Land Mammals, Reptiles, Marine Animals, or Amphibians).

## 🚀 Features
* Classifies animals dynamically based on user input.
* Recognizes a database of common animals (e.g., tigers, lions, crocodiles, blue whales, frogs).
* Provides brief details about the animal's trait or locomotion style upon classification.

## 🛠️ Requirements
* **Python 3.x** (No external libraries required!)

## 💻 How to Run
1. Clone or download this repository.
2. Open your terminal or command prompt.
3. Navigate to the folder containing `classification.py`.
4. Run the script using the following command:
   ```bash
   python classification.py
   ```
